#+TITLE: Manifold Learner

* Overview
Learn a low-dimensional manifold from data, parameterizing it by arc length so that
distances in the latent space match geodesic distances on the manifold.

* Approach
1. Estimate local tangent spaces from nearest neighbors.
2. Integrate arc length along neighbor paths to get intrinsic coordinates.
3. Fit a smooth map from intrinsic coordinates back to ambient space.
